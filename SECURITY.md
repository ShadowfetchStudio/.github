# Reporting security concerns

A repository's own security policy takes precedence over this studio default.

For a potential vulnerability, use **Report a vulnerability** on the repository's Security tab when available. Otherwise, contact [linux@shadowfetchlinux.org](mailto:linux@shadowfetchlinux.org) privately with the repository name and a concise description of the concern.

Include affected versions, impact, and minimal reproduction steps using synthetic data where possible. Never include live passwords, API keys, private keys, or personal datasets. Do not open a public issue containing exploit details or sensitive information.

For Apple apps, follow the app-specific support information at [shadowfetch.com](https://www.shadowfetch.com).

Supported versions and security guarantees are project-specific. Consult the repository's policy and release notes; this default does not promise a response deadline, bounty, or support lifetime.
