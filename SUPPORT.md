# Getting support

## Linux and open-source projects

Read the repository's README and release notes for supported platforms, setup, and known limitations. If the project publishes downloads, use its Releases page.

Use the affected repository's Issues for reproducible bugs and feature requests. Include the project version, operating system, reproduction steps, and relevant redacted logs. Check for an existing report before opening a new one.

Linux and open-source contact: [linux@shadowfetchlinux.org](mailto:linux@shadowfetchlinux.org).

## Apple apps

Find the app on [shadowfetch.com](https://www.shadowfetch.com) and follow its product-specific support link.

## Security concerns

Use the repository's SECURITY.md or its Security tab. Do not publish credentials, private data, or vulnerability details in a public issue. If no project-specific route is listed, follow the [studio security guidance](https://github.com/ShadowfetchStudio/.github/blob/main/SECURITY.md).
